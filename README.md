# jev-trial

TypeSafe の Jev（System One）で遊ぶ置き場

鍵は `TYPESAFE_API_KEY`。リポジトリには入れない。

## fish

前提だけから結論が出るか、型は何か、どれくらいポエムか。

```
魚は空を飛ぶ。空を飛ぶものは月を歌う。月は今夜歌っている。
```

2026-09-18、`jev-latest` が答えたのは `jev-1.13.0`。377 ms。入力 598 token。

| 問い | 答え |
| --- | --- |
| 魚は今夜歌っている、は出るか | noul 0.30（どちらかと言うと出ない） |
| 月は魚である、は出るか | noul 0.08 |
| 論理の型 | chain 0.76（confidence 0.67）。missing は 0.18 |
| ポエム度 | score 1.96。いちばん厚いのは「ポエムだが論理は直線」0.68 |

「魚は今夜歌っている」は実際には出ない。「空を飛ぶものは月を歌う」は、魚が歌うことでも、月が歌うことでもない。chain を選んだのに noul は 0.30 なので、型と結論がずれている。

```
python3 plays/fish.py
```

生の応答は `results/fish.json`。

## tictactoe

3x3。X も O も Jev。空いている番号だけが候補。決着するまで回す。勝ち負けはコードが見る。

各手の指示は、勝つことが目的、勝てるなら取る、相手が次に揃うなら止める、そうでなければ最善手。

盤面はこう並ぶ。

```
1 2 3
4 5 6
7 8 9
```

2026-09-18、どちらも `jev-1.13.0`。8手で O の勝ち。

```
O O X
O X X
O X 9
```

| 手 | 置いたマス | その確率 |
| --- | --- | --- |
| X | 5 | 0.85 |
| O | 2 | 0.21 |
| X | 8 | 0.27 |
| O | 1 | 0.28 |
| X | 3 | 0.29 |
| O | 4 | 0.42 |
| X | 6 | 0.50 |
| O | 7 | 0.58 |

X の初手は中央になった。そのあと O が 1 と 4 を置き、次に 7 で左の列が揃う。X はその直前に 6 を置き、7 を止めなかった。勝てという指示を足しても、止めはまだ抜ける。

```
python3 plays/tictactoe.py
```

一手ずつの確率は `results/tictactoe.json`。
