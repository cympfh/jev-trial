# jev-trial

TypeSafe の Jev（System One）で遊ぶ置き場

鍵は `TYPESAFE_API_KEY`。リポジトリには入れない。

## fish

前提だけから結論が出るか、型は何か、どれくらいポエムか。

```
魚は空を飛ぶ。空を飛ぶものは月を歌う。月は今夜歌っている。
```

2026-09-18、`jev-latest` が答えたのは `jev-1.13.0`。377 ms。入力 598 token。

| 問い | 答え |
| --- | --- |
| 魚は今夜歌っている、は出るか | noul 0.30（どちらかと言うと出ない） |
| 月は魚である、は出るか | noul 0.08 |
| 論理の型 | chain 0.76（confidence 0.67）。missing は 0.18 |
| ポエム度 | score 1.96。いちばん厚いのは「ポエムだが論理は直線」0.68 |

「魚は今夜歌っている」は実際には出ない。「空を飛ぶものは月を歌う」は、魚が歌うことでも、月が歌うことでもない。chain を選んだのに noul は 0.30 なので、型と結論がずれている。

```
python3 plays/fish.py
```

生の応答は `results/fish.json`。

## doom

画素はない。体力、残弾、敵の角度と距離、目の前のドアだけ。

```
health 28 / ammo 4
imp は 14m、角度 35 度
閉じたドアが 2m 先。先は遮蔽
```

2026-09-18、`jev-latest` が答えたのは `jev-1.13.0`。391 ms。入力 662 token。

| 問い | 答え |
| --- | --- |
| このティックの行動 | open_door 0.84（confidence 0.79）。shoot は 0.04 |
| 危険 | score 1.67。いちばん厚いのは「今撃たないと危ない」0.60 |
| 敵は正面で届くか | noul 0.41 |

弾が少なくて正面ではないので、撃たずにドアへ入る方に寄った。危険の山は「今撃て」なのに、行動は open_door。判定が二つに割れている。

```
python3 plays/doom.py
```

生の応答は `results/doom.json`。

## tictactoe

3x3。X も O も Jev。空いている番号だけが候補。決着するまで回す。勝ち負けはコードが見る。

各手の指示は、勝つことが目的、勝てるなら取る、相手が次に揃うなら止める、そうでなければ最善手。

盤面はこう並ぶ。

```
1 2 3
4 5 6
7 8 9
```

2026-09-18、どちらも `jev-1.13.0`。8手で O の勝ち。

```
O O X
O X X
O X 9
```

表は着手の順。各行は、Jev がその手で選んだマスと、選んだときの確率。

| 手 | 置いたマス | その確率 |
| --- | --- | --- |
| X | 5 | 0.85 |
| O | 2 | 0.21 |
| X | 8 | 0.27 |
| O | 1 | 0.28 |
| X | 3 | 0.29 |
| O | 4 | 0.42 |
| X | 6 | 0.50 |
| O | 7 | 0.58 |

X の初手は中央になった。そのあと O が 1 と 4 を置き、次に 7 で左の列が揃う。X はその直前に 6 を置き、7 を止めなかった。勝てという指示を足しても、止めはまだ抜ける。

```
python3 plays/tictactoe.py
```

一手ずつの確率は `results/tictactoe.json`。

## abstain

文を返金、文句、判断できない、の三つに分ける。いちばん高い確率が 0.6 未満なら、コードが棄権する。閾値はプロンプトではなくコードにある。

2026-09-18、`jev-1.13.0`。三回とも 0.6 以上なので、棄権は出なかった。

表は文ごとに、Jev が選んだ分類と、その確率。0.6 未満なら棄権。

| 文 | 選んだ分類 | 確率 | コード |
| --- | --- | --- | --- |
| 注文が二つ届いた。余分な方を返金してください。 | refund | 1.00 | 動く |
| 届いた箱が凹んでいた。本当に腹が立つ。 | complaint | 0.97 | 動く |
| この料金、どういうこと？ | unclear | 0.60 | 動く |

3つ目はぴったり 0.6。未満ではないので動く。内訳は unclear 0.60、complaint 0.40、refund 0.00。confidence は 0.39 で、選んだ確率より低い。

```
python3 plays/abstain.py
```

生の応答は `results/abstain.json`。
